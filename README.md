# 🐍 Oasis Infobyte Python Internship – 3 Tasks

This repository contains the three projects I completed as part of my **Python Programming Internship at Oasis Infobyte**.

## 📌 Tasks Completed

### 🔐 Task 1 – Random Password Generator

A Python-based application that generates strong and random passwords.

**Features:**

* Generates random passwords
* Allows different password lengths
* Includes letters, numbers, and special characters
* Helps create secure passwords

**Technologies Used:**

* Python
* `random` module
* `string` module

---

### ⚖️ Task 2 – BMI Calculator

A simple Python application that calculates a person's **Body Mass Index (BMI)** based on their height and weight.

**Features:**

* Takes height and weight as input
* Calculates BMI
* Displays the BMI value
* Provides the corresponding BMI category

**BMI Formula:**

`BMI = Weight (kg) / Height² (m²)`

**Technologies Used:**

* Python

---

### 🌦️ Task 3 – Basic Weather App

A basic weather application that displays weather information for a selected location.

**Features:**

* Accepts a city/location as input
* Fetches weather information
* Displays weather details in a simple interface
* User-friendly design

**Technologies Used:**

* Python
* HTML
* CSS
* Weather API
